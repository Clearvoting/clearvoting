# Design panel — 2026-09-18

Four independent redesign approaches were produced from the same review (`docs/reviews/2026-09-10-redesign-review.md`)
and brief, each with a proposal and self-contained real-data mockups (open the `.html` files directly in a browser;
mobile-first, 375px → 768px → 1100px). Three judges (citizen, PM, designer) scored each on task-first, trust/neutrality,
feasibility, mobile, coherence and effort/risk (max 60 per judge, 180 total).

| Approach | Thesis | Total | Winner votes |
|---|---|---|---|
| `spine/` | Rebuild around one job: ZIP → your 3 members → record-first member page → bill page that answers "how did my reps vote" | **135** | citizen, PM |
| `broadsheet/` | Finish the civic-broadsheet system on every page; one stylesheet; ruthless editing | 133 | designer |
| `share/` | Every member/bill page is a phone landing page for someone arriving from a shared link | 130 | — |
| `evolve/` | Conservative baseline: keep every page and module, fix each finding in place | 130 | — |

The final spec (`../2026-09-18-clearvoting-redesign-design.md`) is built on Spine with grafts from the other three;
§2.4 of the spec records every graft adopted and declined.
